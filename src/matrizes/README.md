# Matrizes
Esta pasta reúne estudos sobre arrays bidimensionais em Java.
## Objetivo do módulo
O foco aqui é entender estruturas com linhas e colunas, leitura por posição e percursos aninhados.
## Lógica dos arquivos

Exemplo introdutório com criação, preenchimento e exibição de matriz.
