# Camada `entities`

Esta pasta reúne as entidades de domínio usadas pela aplicação.

## Entidades do módulo

- `Seller`
- `Department`

## O que observar

- as classes representam os dados do banco em objetos Java;
- `Seller` possui associação com `Department`;
- os DAOs montam essas entidades a partir dos dados retornados pelo banco.
