# JDBC

Esta pasta reúne os estudos de acesso a banco de dados com JDBC.

## O que você encontra aqui

- exemplos progressivos de conexão e manipulação de dados;
- tratamento de exceções ligadas ao banco;
- uma aplicação mais estruturada com padrão DAO.

## Aplicação principal do módulo

O bloco mais completo desta trilha é:

- [`demodaojdbc/`](demodaojdbc/)

Ele demonstra uma evolução importante do JDBC puro para uma organização em camadas, com:

- entidades;
- interfaces DAO;
- implementações JDBC;
- classe de execução para testes das operações.

## Ordem sugerida de estudo

1. exemplos básicos de `jdbc/exemplo1` até `jdbc/exemplo6`;
2. [`demodaojdbc/`](demodaojdbc/) para ver a aplicação mais organizada.
