# Programação Funcional e Expressões Lambda

Esta pasta concentra os estudos ligados a recursos funcionais do Java.

## Objetivo do módulo

A proposta aqui é sair do uso puramente imperativo da linguagem e avançar para uma forma mais declarativa de escrever código, principalmente com:

- expressões lambda;
- interfaces funcionais;
- referências de método;
- `Stream API`;
- composição de operações como `filter`, `map`, `sorted`, `reduce` e `collect`.

## Lógica atual das subpastas

### `demo1/`
Base inicial do módulo, com exemplos de apoio e entidades simples.

### `consumer/`
Estudos sobre a interface funcional `Consumer`, usada quando o objetivo é executar uma ação sobre um objeto sem retornar valor.

### `function/`
Estudos sobre a interface funcional `Function`, usada para transformar um valor em outro.

### `predicate/`
Estudos sobre a interface funcional `Predicate`, usada para avaliar condições e retornar `true` ou `false`.

### `expressividade/`
Exemplos voltados a estilo de escrita, leitura do código e ganho de clareza com abordagens funcionais.

### `objetosdeprimeiraordem/`
Conteúdo voltado ao conceito de tratar funções e comportamentos como valores reutilizáveis.

### `transparenciareferencial/`
Pasta voltada a conceitos mais teóricos de programação funcional, importantes para entendimento de previsibilidade e composição.

### `stream/`
Parte central do módulo.
Aqui ficam os exemplos de criação de streams, pipelines, operações intermediárias, operações terminais e exercícios resolvidos.

### `problemaExemplo/`
Exemplo mais completo e prático, com organização por `application`, `entities` e `services`.
É um bom modelo para conteúdos futuros que precisem de mais estrutura.

### `exerciciodefixacao/`
Espaço para exercícios aplicados, onde os conceitos do módulo são colocados em prática com leitura de dados, filtragem, transformação e redução.

## O que este módulo agrega ao projeto

Esta pasta mostra a transição para uma escrita mais declarativa em Java, com foco em:

- uso de lambda no dia a dia;
- aplicação prática de interfaces funcionais;
- leitura e composição com `Stream API`;
- evolução da base para conceitos mais intermediários.
