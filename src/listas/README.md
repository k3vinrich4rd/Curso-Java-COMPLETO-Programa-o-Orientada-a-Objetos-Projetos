# Listas
Esta pasta reúne estudos sobre listas em Java.
## Objetivo do módulo
O foco aqui é entender estruturas dinâmicas com inserção, remoção, busca, filtragem e percursos.
## Lógica dos arquivos
### `ListasExemplo1.java`
Exemplo principal com operações básicas de `List`.
### `exercicios/`
Área de prática para consolidar o uso de listas.
## Ordem sugerida de estudo
1. `ListasExemplo1.java`
2. `exercicios/`
## O que este módulo agrega ao projeto
Esse conteúdo ajuda a fazer a transição entre arrays fixos e coleções mais flexíveis da linguagem.
