# Vetores
Esta pasta reúne estudos sobre arrays em Java.
## Objetivo do módulo
O foco aqui é entender como trabalhar com estruturas de tamanho fixo, leitura de dados e percursos com índice.
## Lógica dos arquivos
### `ProblemaExemploAltura.java`
Exemplo aplicado com vetor e leitura de dados.
### `exercicios/`
Área prática para consolidar o uso de vetores.
### `objeto/`
Estudos que combinam vetores com objetos.
## Ordem sugerida de estudo
1. `ProblemaExemploAltura.java`
2. `exercicios/`
3. `objeto/`
## O que este módulo agrega ao projeto
Esse conteúdo ajuda a construir base para estrutura de dados linear, leitura sequencial e organização de coleções simples.
