# Funções Matemáticas
Esta pasta reúne estudos sobre operações matemáticas utilitárias em Java.
## Objetivo do módulo
O foco aqui é entender o uso da classe `Math` para:
- raiz quadrada;
- potenciação;
- valor absoluto;
- operações numéricas frequentes.
## Lógica dos arquivos
### `UtilizandoMath.java`
Exemplo introdutório com métodos matemáticos prontos da linguagem.
## Ordem sugerida de estudo
1. `UtilizandoMath.java`
## O que este módulo agrega ao projeto
Esse conteúdo reforça a base numérica da linguagem e prepara o terreno para exercícios com cálculos e fórmulas.
