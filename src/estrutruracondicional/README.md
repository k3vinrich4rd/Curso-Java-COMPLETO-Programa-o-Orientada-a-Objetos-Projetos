# Estrutura Condicional
Esta pasta reúne estudos sobre tomada de decisão em Java.
## Objetivo do módulo
O foco aqui é entender como controlar o fluxo do programa com:
- `if` e `else`;
- `switch`;
- operador ternário;
- expressões condicionais.
## Lógica dos arquivos
Os arquivos da pasta seguem uma trilha de exercícios e exemplos de decisão lógica, incluindo:
- `SwitchCase.java`
- `CondicionalTernario.java`
- série `Exercicio1.java` até `Exercicio8.java`
## Ordem sugerida de estudo
1. `SwitchCase.java`
2. `CondicionalTernario.java`
3. exercícios numéricos e lógicos da pasta
## O que este módulo agrega ao projeto
Esse conteúdo ajuda a construir base para regras de decisão, validação e controle de execução.
