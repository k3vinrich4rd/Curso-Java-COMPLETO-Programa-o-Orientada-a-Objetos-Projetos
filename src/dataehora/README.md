# Data e Hora

Esta pasta reúne estudos sobre manipulação de datas e horários em Java.

## Objetivo do módulo

O foco aqui é entender como trabalhar com:

- representação de datas e horários;
- criação de instâncias de tempo;
- conversões básicas;
- operações comuns envolvendo data e hora.

## Lógica dos arquivos

- `Exemplo1.java`
- `Exemplo2.java`
- `Exemplo3.java`
- `CalculoDataHora.java`

Esses arquivos funcionam como uma sequência de exemplos para fixar o uso das classes de data e hora da linguagem.

## Ordem sugerida de estudo

1. `Exemplo1.java`
2. `Exemplo2.java`
3. `Exemplo3.java`
4. `CalculoDataHora.java`

## O que este módulo agrega ao projeto

Esse bloco ajuda a construir uma base importante para aplicações que lidam com agendamento, registros temporais e formatação de datas.
