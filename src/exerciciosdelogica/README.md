# Exercícios de Lógica
Esta pasta reúne exercícios curtos de raciocínio lógico em Java.
## Objetivo do módulo
O foco aqui é praticar interpretação de enunciado, cálculo simples e tradução de lógica para código.
## Lógica dos arquivos
Os arquivos abordam temas como:
- antecessor e sucessor;
- média aritmética;
- reajuste;
- porcentagem;
- leitura de idade;
- salário mínimo.
## Ordem sugerida de estudo
A recomendação é percorrer os arquivos em sequência, usando cada um como treino de leitura e implementação.
## O que este módulo agrega ao projeto
Esse conteúdo reforça a base lógica do repositório e ajuda na transição entre teoria e prática com exercícios curtos.
