# Interfaces

Esta pasta reúne estudos sobre interfaces no Java, com foco tanto em conceito quanto em aplicação prática.

## Objetivo do módulo

Aqui o foco é entender como interfaces ajudam a:

- definir contratos;
- desacoplar regras de implementação;
- reaproveitar comportamento;
- padronizar soluções mais flexíveis;
- trabalhar com ordenação e métodos default.

## Lógica das subpastas

### `comparable/`
Estudos sobre ordenação natural de objetos, mostrando como implementar `Comparable` para definir critérios de comparação.

### `defaultsmethods/`
Conteúdo voltado ao uso de métodos default em interfaces.
É uma parte importante para entender evolução de APIs e reaproveitamento de comportamento.

### `exerciciofixacao/`
Área prática do módulo, com exercício aplicado e separação de responsabilidades em `entities`, `services` e `teste`.

### `solucaoproblema1/`
Primeira abordagem de solução para um problema usando interfaces e modelagem orientada a contrato.

### `solucaoproblema2/`
Evolução da solução anterior, com melhor separação entre aplicação e modelo.

### `solucaoproblema3/`
Versão mais refinada da proposta de solução, útil para comparar decisões de modelagem.

## Ordem sugerida de estudo

1. `comparable/`

## O que este módulo agrega ao projeto

Esta pasta é importante porque mostra um avanço da base da linguagem para um nível mais estruturado de modelagem, com foco em:

- contratos;
- abstração;
- organização de regras;
- flexibilidade de design.
