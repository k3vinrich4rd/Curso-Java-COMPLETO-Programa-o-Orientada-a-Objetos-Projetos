# Entities

Esta pasta reúne entidades simples reutilizadas em exemplos introdutórios do projeto.

## Objetivo do módulo

O foco aqui é concentrar classes de domínio pequenas, usadas para praticar:

- encapsulamento;
- construtores;
- getters e setters;
- representação textual de objetos.

## Lógica dos arquivos

### `Product.java`
Classe de produto usada em exemplos de orientação a objetos e manipulação de dados.

## Ordem sugerida de estudo

1. `Product.java`

## O que este módulo agrega ao projeto

Esse conteúdo ajuda a construir base para modelagem simples de objetos, algo que aparece em vários outros módulos do repositório.
