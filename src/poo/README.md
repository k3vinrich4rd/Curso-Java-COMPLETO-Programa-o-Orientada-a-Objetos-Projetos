# Programação Orientada a Objetos

Esta pasta concentra a base dos estudos de POO dentro do projeto.

## Objetivo do módulo

Aqui estão os conteúdos voltados a construção dos fundamentos de modelagem com objetos, como:

- classes e objetos;
- atributos e métodos;
- encapsulamento;
- construtores;
- membros estáticos;
- organização de lógica em estruturas orientadas a objeto.

## Lógica das subpastas

### `exercicios/`
Reúne exercícios práticos de POO, com temas como funcionário, retângulo e estudante.
É uma parte importante para consolidar a base antes de avançar para módulos mais abstratos.

### `membrosestaticos/`
Conteúdo voltado ao uso de membros estáticos, incluindo exemplos e exercícios aplicados.

### `Product/`
Conjunto de arquivos focados na classe `Product`, útil para revisar criação de classe, construtores, manipulação de atributos e evolução da modelagem.

### `Triangulo/`
Área voltada a exemplos com triângulo, incluindo comparação entre abordagem procedural e orientada a objetos.
É uma parte boa para perceber o ganho de estrutura com POO.

## Ordem sugerida de estudo

1. `Triangulo/`
2. `Product/`
3. `exercicios/`
4. `membrosestaticos/`

## O que este módulo agrega ao projeto

Esta pasta é essencial porque ela sustenta boa parte dos conteúdos seguintes do repositório.
Ela reforça:

- organização de código;
- modelagem de domínio;
- pensamento orientado a objetos;
- base necessária para herança, interfaces, exceções e serviços.
