# Estrutura Repetitiva
Esta pasta reúne estudos sobre laços de repetição em Java.
## Objetivo do módulo
O foco aqui é entender como repetir instruções com:
- `while`;
- `for`;
- `do while`;
- controle de contagem e condição.
## Lógica das subpastas e arquivos
### `ProblemaExemploWhile.java`
Exemplo introdutório com `while`.
### `ProblemaExemploFor.java`
Exemplo introdutório com `for`.
### `ExemploDoWhile.java`
Exemplo com `do while`.
### `exercicios/`
Área prática para consolidar laços de repetição.
## Ordem sugerida de estudo
1. `ProblemaExemploWhile.java`
2. `ProblemaExemploFor.java`
3. `ExemploDoWhile.java`
4. `exercicios/`
## O que este módulo agrega ao projeto
Esse conteúdo fortalece lógica de repetição, contagem e processamento de sequências de dados.
