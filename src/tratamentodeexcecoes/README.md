# Tratamento de Exceções

Esta pasta reúne estudos sobre tratamento de erros e controle de falhas em Java.

## Objetivo do módulo

O foco aqui é entender como a linguagem lida com situações excepcionais e como estruturar código mais seguro e previsível com:

- `try` e `catch`;
- `finally`;
- exceções personalizadas;
- propagação de erros;
- organização de fluxos com validação e tratamento.

## Lógica das subpastas e arquivos

### `EstruturaTryCatch.java`
Exemplo introdutório para entender captura de exceções e tratamento controlado de erro.

### `EstruturaFinally.java`
Exemplo dedicado ao uso de `finally`, importante para recursos que precisam ser encerrados corretamente.

### `execoespersonalizadas/`
Área voltada à criação e uso de exceções personalizadas.
Apesar do nome atual poder ser ajustado no futuro, o conteúdo é importante para entender regras de domínio mais bem definidas.

### `exerciciodefixacao/`
Parte prática do módulo, com organização em subpastas como `exceptions`, `model` e `teste`.
É um bom espaço para consolidar o tratamento de erros em cenários mais aplicados.

## Ordem sugerida de estudo

1. `EstruturaTryCatch.java`
2. `EstruturaFinally.java`
3. `execoespersonalizadas/`
4. `exerciciodefixacao/`

## O que este módulo agrega ao projeto

Este módulo é importante porque mostra maturidade no tratamento de falhas, algo essencial para qualquer aplicação real.
Ele reforça:

- robustez;
- previsibilidade;
- organização do fluxo de erro;
- clareza na separação entre regra de negócio e tratamento técnico.
