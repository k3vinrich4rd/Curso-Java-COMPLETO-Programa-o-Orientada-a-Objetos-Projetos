# Map

Esta pasta reúne estudos sobre estruturas de mapeamento em Java.

## Objetivo do módulo

O foco aqui é entender coleções baseadas em chave e valor, observando principalmente:

- associação entre chave e valor;
- busca por chave;
- iteração sobre entradas;
- aplicações práticas de mapeamento.

## Lógica das subpastas

### `demo1/`
Primeira demonstração do uso de `Map`, com foco nos conceitos fundamentais da estrutura.

### `demo2/`
Evolução do módulo com uso de entidade e aplicação prática de mapeamento.

### `exerciciodefixacao/`
Área de prática para consolidar o uso de `Map` em problemas mais aplicados.

## Ordem sugerida de estudo

1. `demo1/`
2. `demo2/`
3. `exerciciodefixacao/`

## O que este módulo agrega ao projeto

Esse conteúdo ajuda a entender estruturas muito usadas para indexação, contagem, agrupamento e associação entre informações.
