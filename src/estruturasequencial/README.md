# Estrutura Sequencial
Esta pasta reúne estudos sobre os fundamentos iniciais da lógica em Java.
## Objetivo do módulo
O foco aqui é entender:
- entrada e saída de dados;
- variáveis;
- operações básicas;
- execução sequencial de instruções.
## Lógica das subpastas e arquivos
### `exemplos/`
Exemplos introdutórios da linguagem.
### `exercicios/`
Exercícios para fixar os primeiros conceitos.
### `ExercicioDeFixacao.java`
Arquivo de prática aplicado ao conteúdo da fase sequencial.
## Ordem sugerida de estudo
1. `exemplos/`
2. `ExercicioDeFixacao.java`
3. `exercicios/`
## O que este módulo agrega ao projeto
Esse bloco forma a base de leitura, escrita e raciocínio que sustenta todos os conteúdos seguintes.
