# Funções de String
Esta pasta reúne estudos sobre manipulação de texto em Java.
## Objetivo do módulo
O foco aqui é entender operações comuns com `String`, como:
- transformação de texto;
- busca de trechos;
- recorte;
- divisão de conteúdo;
- comportamento de métodos utilitários.
## Lógica dos arquivos
### `StringFuncoes.java`
Exemplo voltado às operações mais comuns com strings.
### `StringSplit.java`
Exemplo focado em divisão de texto com `split`, útil para leitura e tratamento de dados.
## Ordem sugerida de estudo
1. `StringFuncoes.java`
2. `StringSplit.java`
## O que este módulo agrega ao projeto
Esse conteúdo ajuda a construir base para manipulação de entrada, leitura de arquivos e tratamento de dados textuais.
