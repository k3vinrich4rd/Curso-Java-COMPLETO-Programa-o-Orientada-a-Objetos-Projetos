# Generics, Set e Map

Esta pasta reúne estudos sobre tipagem genérica, comparação entre objetos e uso de coleções como `Set` e `Map`.

## Objetivo do módulo

O foco aqui é avançar em temas que costumam marcar uma transição do Java básico para um nível mais intermediário, principalmente em:

- reutilização de código com generics;
- segurança de tipos;
- wildcards (`?`) e seus limites;
- comparação correta entre objetos;
- impacto de `hashCode` e `equals` nas coleções.

## Lógica das subpastas

### `generics/`
Conteúdo voltado à generalização de tipos e reaproveitamento de lógica.
É a base para entender como escrever código mais flexível e reutilizável.

### `hascodeeequals/`
Bloco voltado à identidade e comparação entre objetos.
Apesar do nome atual da pasta poder ser melhorado no futuro, a proposta aqui é estudar quando dois objetos devem ser considerados iguais e como isso afeta estruturas de dados.

### `tiposcuringa/`
Área dedicada aos tipos curinga (`wildcards`) e seus limites.
É uma parte importante para compreender flexibilidade e restrições de generics em Java.

## Ordem sugerida de estudo

1. `generics/`
2. `tiposcuringa/`
3. `hascodeeequals/`

## O que este módulo agrega ao projeto

Esse conjunto é importante porque mostra evolução em temas como:

- modelagem mais correta de objetos;
- comportamento real de coleções;
- reaproveitamento com generics;
- leitura mais madura da linguagem Java.
