# Set

Esta pasta reúne estudos sobre conjuntos em Java.

## Objetivo do módulo

O foco aqui é entender como funcionam coleções que não permitem duplicidade de elementos, com atenção para:

- comportamento de `HashSet`;
- preservação de ordem em `LinkedHashSet`;
- ordenação natural em `TreeSet`;
- operações comuns com conjuntos.

## Lógica das subpastas e arquivos

### `ExemploEmConjunto.java`
Exemplo introdutório para entender o conceito de conjunto.

### `HashSetExemplo.java`
Mostra o uso de `HashSet`, com foco em desempenho e ausência de ordem garantida.

### `LinkedHashSetExemplo.java`
Mostra o uso de `LinkedHashSet`, útil quando é importante manter a ordem de inserção.

### `TreeSetExemplo.java`
Mostra o uso de `TreeSet`, com ordenação dos elementos.

### `demo1/`
Demonstração inicial do módulo.

### `operacoes/`
Conteúdo voltado às operações mais comuns com conjuntos, como remoção e filtragem.

### `exerciciodefixacao/`
Área prática para consolidar o uso de conjuntos em exercícios.

### `exercicioresolvido/`
Espaço de solução aplicada, útil para revisão.

Este módulo ajuda a entender melhor escolha de coleção, unicidade de dados e impacto da ordenação em estruturas de conjunto.
